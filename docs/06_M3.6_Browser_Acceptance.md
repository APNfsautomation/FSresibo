## Checkpoint 3 implementation evidence

- Automated suite: 139 passing tests, zero failures. Includes executable app bootstrap/auth cleanup, route/visibility/state retention, exact money display, and existing transaction regression coverage.
- Node v24.19.0 engine benchmark on Windows / Intel i7-14700HX: eight 32-input scenarios, all three strategies, both APIs, five measured repeats each. Worst median 82.14 ms; maximum 104.21 ms. Repeated results retained identical identities/order. Post-call heap observations are approximate, not peak-memory or mobile-browser measurements.
- Local in-app browser harness uses real HTML/CSS, Quick UI, and navigation, with transaction visibility adapters and no authenticated backend. Initial checks passed for desktop module switching, keyboard alternative selection, highlights, retained inputs/selection, light/dark surfaces, and narrow-width stacking without horizontal overflow. Two observed contrast/header-overlap issues were corrected in CSS.
- This evidence does not establish hosted authentication, real transaction acceptance, representative mobile performance, screen-reader acceptance, or production rollout. Those remain Product Owner checks above.
