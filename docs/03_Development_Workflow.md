# Development Workflow

1. Discuss feature.
2. Update docs if architecture changes.
3. Ask Codex to inspect repository.
4. Review implementation plan.
5. Approve implementation.
6. Test on Synology.
7. Commit.
8. Push.
9. Verify deployment.

For new Codex chats:
- Attach GitHub repository.
- Read /docs.
- Summarize understanding before coding.
